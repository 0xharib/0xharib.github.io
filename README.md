# haribalaji.net

The source for [haribalaji.net](https://haribalaji.net), Hari Balaji's personal
writing site. It is a Jekyll static site with a customized, TeXt-derived theme,
hosted on GitHub Pages. The archive currently contains 59 essays published from
2010 onward, covering AI and agents, data experiments, books, science fiction,
work, and cricket.
